## Ошибки rclone

| Что в логе | Что значит | Что делать |
|---|---|---|
| `410 GoneError` / «Ресурс больше недоступен» на любые папки | подключение создано через `rclone config` приложением rclone, Яндекс его не пускает к файлам | подключитесь по токену Полигона: `scripts/add-yandex-remote.*` |
| `unable to get RefreshToken` | в секции `[yandex]` нет `refresh_token` | используйте скрипт подключения: он добавляет заглушку `"refresh_token":"unused"` |
| `401 Unauthorized` | токен Полигона истёк или отозван | получите новый и замените `access_token` в конфиге (или удалите секцию и запустите скрипт заново) |
| `timeout awaiting response headers` | файл лежит на недоступном сейчас сервере Яндекса или ссылка выдаётся слишком долго | ничего, запустите копирование позже: докачается только недостающее |
| `500 Internal Server Error` | то же, со стороны Яндекса | то же |
| `failed to open source object: 503` (WebDAV) | WebDAV Яндекса перегружен | используйте подключение `yandex` (REST), а не WebDAV |
| `googleapi: Error 403: User rate limit exceeded` / остановка на лимите | Google: больше 750 ГБ в сутки не залить | запустите на следующий день |
| `Too many items` (в `yd.js`) | пачка больше 40 | `node yd.js move state 100000 40` |
| код выхода `5` | «временная ошибка»: часть файлов не скопирована | обычное дело сейчас, см. список `*-failed.txt` и повторите позже |

Коды выхода rclone: [rclone.org/docs/#exit-code](https://rclone.org/docs/#exit-code).

## Половина файлов не копируется. Это навсегда?

Неизвестно. На тестовом аккаунте 13.10.2026 около половины файлов не отдавались ни через REST API,
ни через WebDAV, и набор не менялся между попытками. Ссылки на скачивание таких файлов ведут на серверы
`*.klg.storage.yandex.net` (Калуга), которые принимают соединение и молчат. Яндекс не сообщал о потере
данных, так что разумно сохранить всё доступное сейчас и повторять копирование каждый день.
Если файлы у вас есть где-то ещё (старый компьютер, телефон, почта), соберите их оттуда по списку
`*-failed.txt`.

## Копирование идёт очень медленно

- Каждый недоступный файл съедает до двух минут тайм-аутов. Пока в очереди много таких файлов, скорость
  в байтах низкая. Добавьте потоков (`-Transfers 32` / `TRANSFERS=32`): ожидающие потоки почти не тратят ресурсы.
- Яндекс сейчас выдаёт ссылки на скачивание от 1 до 60 секунд, это не лечится настройками.
- На VPS для повторных проходов можно исключить известные мёртвые файлы: [vps.md](vps.md#3-сначала-самое-важное-мёртвые-файлы--потом).

## Как отозвать токен

Токен Полигона действует около года и даёт полный доступ к Диску. Когда копирование закончено:

1. Удалите секцию `[yandex]` из конфига rclone (`rclone config delete yandex`).
2. В [Яндекс ID](https://id.yandex.ru) откройте список приложений, у которых есть доступ к аккаунту,
   и отключите «Полигон» Яндекс Диска (точное название пункта меню может отличаться).
3. Проверьте: если отзыв сработал, `rclone about yandex:` (пока секция ещё есть) отвечает `401`.
   Если пункт меню не нашёлся, смените пароль и выйдите на всех устройствах, затем проверьте так же.

## Можно ли `sync` вместо `copy`?

Не нужно. `sync` удаляет в месте назначения всё, чего нет на Диске. Если на Диске что-то пропадёт
или Яндекс временно покажет пустую папку, `sync` сотрёт это и в копии. Здесь везде `copy`.
